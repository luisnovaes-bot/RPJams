# 0002 - Sala permanente por link, sem login

**Status:** aceito (2026-10-21)

## Contexto
O grupo é pequeno (4 a 8 pessoas) e privado. Login seria atrito sem ganho.

## Decisão
Cada sala é permanente e tem dois links: um secreto de mestre (controle total) e um de jogador (só ouvir). A posse do link é a autorização.

## Consequências
- Se o link de mestre vazar, qualquer pessoa controla a sala. Se for perdido, a sala fica sem controle. O app deve pedir para o mestre salvar o link ao criar a sala.
- Abrir para outros grupos no futuro pode exigir login ou forma de recuperar o link de mestre.
